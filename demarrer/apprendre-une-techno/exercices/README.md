# Exercices : Apprendre une nouvelle techno

> 🔙 Retour à la [fiche](../README.md)

Choisissez une techno que vous ne connaissez pas encore, par exemple une que votre formation abordera bientôt. Gardez la même pour les trois exercices, et notez votre progression dans votre fichier `notes.md`.

## 1. Vérifier

1. Situez la techno en trois phrases : à quoi elle sert, quel problème elle résout, à quoi elle ressemble parmi ce que vous connaissez ;
2. Trouvez sa documentation officielle et son _Getting Started_ ;
3. Installez-la et faites fonctionner le premier exemple du _Getting Started_.

**Résultat attendu** : vos trois phrases, le lien vers la doc officielle, et le premier exemple qui fonctionne sur votre machine.

## 2. Manipuler

1. Choisissez un mini-projet d'une seule fonctionnalité, par exemple : un convertisseur de températures, un compteur de mots dans une phrase, une liste de courses affichée à l'écran.
2. Écrivez les étapes en commentaires, puis codez-les.
3. Ouvrez un dossier vide et refaites le projet **sans regarder** votre première version.
4. Expliquez chaque ligne à un·e camarade, ou à voix haute. Notez les lignes que vous n'avez pas su expliquer, et cherchez-les dans la doc !

## 3. Explorer

Ajoutez à votre mini-projet une fonctionnalité qui demande une notion **absente du _Getting Started_** : enregistrer le résultat dans un fichier, lire une saisie de l'utilisateur, trier une liste, ... À vous de trouver comment faire dans la **documentation de référence** de la techno !

Notez dans `notes.md` le lien exact de la page qui vous a permis d'y arriver. Utile pour vous relire plus tard !
