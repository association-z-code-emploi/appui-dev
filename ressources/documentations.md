# Documentations

La documentation officielle d'une techno est la source la plus fiable et la plus à jour : c'est le premier réflexe quand on cherche comment faire quelque chose !

> ℹ️ Pour savoir s'y repérer, voir la fiche [Lire une documentation](../demarrer/lire-une-doc/).

Toutes les documentations ci-dessous sont **officielles**, sauf mention contraire. Elles décrivent en général la **dernière version** de la techno : on vérifie toujours qu'elle correspond à celle qu'on utilise.

## Front-end

- [MDN Web Docs](https://developer.mozilla.org/fr/) : la référence pour HTML, CSS et JavaScript, éditée par Mozilla. Ce n'est pas la spécification officielle, mais c'est la doc que tout le monde consulte. La version anglaise est la plus complète.
- [TypeScript](https://www.typescriptlang.org/docs/) (en anglais) : le _Handbook_ est la meilleure entrée pour passer de JavaScript à TypeScript.
- [React](https://fr.react.dev/) : la section _Apprendre_ pour démarrer, la section _Référence_ pour vérifier une API.
- [Sass](https://sass-lang.com/documentation/) (en anglais) : la syntaxe et les modules, avec des exemples en SCSS.

## Back-end

- [PHP](https://www.php.net/manual/fr/) : le manuel complet, avec une page par fonction.
- [Symfony](https://symfony.com/doc/current/index.html) (en anglais) : le guide _Getting Started_ explique aussi l'organisation d'un projet Symfony.
- [Laravel](https://laravel.com/docs) (en anglais) : à lire dans l'ordre pour les premières sections.
- [Node.js](https://nodejs.org/docs/latest/api/) (en anglais) : la référence des modules intégrés à Node (fichiers, serveur HTTP, ...).

## Bases de données

- [MySQL](https://dev.mysql.com/doc/) (en anglais) : le manuel de référence, à consulter pour une commande ou un type précis.
- [PostgreSQL](https://www.postgresql.org/docs/) (en anglais) : très complète, avec un tutoriel d'introduction au SQL.
- [SQLite](https://www.sqlite.org/docs.html) (en anglais) : la base la plus simple pour pratiquer le SQL, sans serveur à installer.
- [MongoDB](https://www.mongodb.com/docs/) (en anglais) : la référence des bases orientées documents.

## Outils

- [Git](https://git-scm.com/book/fr/v2) : le livre _Pro Git_, gratuit et traduit en français, du premier commit aux usages avancés.
- [GitHub](https://docs.github.com/fr) : tout ce qui concerne GitHub lui-même (repos, Issues, Pages, ...).
- [Visual Studio Code](https://code.visualstudio.com/docs) (en anglais) : réglages, raccourcis, terminal intégré, extensions.

## Tests

- [Jest](https://jestjs.io/docs/getting-started) (en anglais) : pour tester du code JavaScript.
- [PHPUnit](https://phpunit.de/documentation.html) (en anglais) : pour tester du code PHP ; la page renvoie vers le manuel de chaque version maintenue.
